#### Task 2.4: AI Query Enhancement

```go
func EnhanceDorkQuery(query string, target string, provider string) ([]string, error) {
    prompt := fmt.Sprintf(`Generate 5-10 Google dork variations for security testing.

Target: %s
Base query: %s

Return JSON array of optimized dork queries. Include:
- site: operator for the target
- filetype: variations
- inurl:/intitle: combinations
- Error message patterns
- Sensitive file patterns`, target, query)

    // Call AI provider (DeepSeek default)
    response, err := aibridge.Query(prompt, provider)

    // Parse JSON response
    var dorks []string
    json.Unmarshal(response, &dorks)

    return dorks, nil
}
```

#### Task 3.3: BYOK + Ollama Offline
