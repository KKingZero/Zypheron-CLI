## Token Usage

AI tokens are consumed when using cloud AI features:
- AI chat assistance
- Vulnerability analysis
- Autonomous scanning
- Report generation
- Attack planning

**Token Reset:** Monthly on billing date. No rollover.

**Running low?** Upgrade plan or use self-hosted Ollama (free, unlimited).

## FAQ

**Can I use my own API keys?**
Yes. Bring Your Own Key (BYOK) is supported. You can add your own Claude, OpenAI, and other provider keys with any plan.

**What happens if I run out of tokens?**
You can continue using local workflows and AI-native tooling paths. Cloud AI features will be unavailable until your tokens reset.

**Is there a free trial?**
The free tier is always available. No credit card required.

**Can I cancel anytime?**
Yes. Cancel via CLI (`zypheron billing`) or the web portal. Access continues until the end of your billing period.

**Enterprise custom pricing?**
Contact sales@zypheron.io for 10+ seats or custom requirements.
