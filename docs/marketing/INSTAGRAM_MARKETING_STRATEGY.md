## 2. Feed Aesthetic

### Color Palette
```
Primary:    #0D1117 (GitHub dark)     - Backgrounds
Secondary:  #58A6FF (Cyber blue)      - Accents, CTAs
Accent 1:   #7EE787 (Terminal green)  - Success states
Accent 2:   #FF7B72 (Alert red)       - Warnings
Neutral:    #C9D1D9 (Light gray)      - Text
```

### Typography Guidelines
- **Headlines:** JetBrains Mono, Fira Code, or SF Mono (monospace)
- **Body text:** Inter, SF Pro for readability
- **Terminal text:** Always monospace with syntax highlighting

### Template Elements
- Zypheron logo watermark (bottom right, 15% opacity)
- Consistent corner radius (8px)
- Terminal-style frame for code screenshots
- Subtle scan-line effect (optional)
